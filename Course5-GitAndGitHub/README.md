# Simple Interest Calculator

This repository contains a simple interest calculator script written in Bash.

## What is Simple Interest?

Simple Interest is calculated using the formula:
**SI = (P * R * T) / 100**

Where:
- **P** = Principal amount
- - **R** = Rate of interest per year (in percentage)
  - - **T** = Time period in years
   
    - ## Repository Contents
   
    - - `simple-interest.sh` - A Bash shell script that calculates simple interest based on user input
     
      - ## Usage
     
      - Run the shell script to calculate simple interest:
     
      - ```bash
        bash simple-interest.sh
        ```

        The script will prompt you to enter:
        1. The principal amount
        2. 2. The rate of interest (per year)
           3. 3. The time period (in years)
             
              4. It will then output the calculated simple interest.
